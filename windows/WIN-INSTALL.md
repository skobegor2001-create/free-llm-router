# Установка на Windows 11

Среда не требует прав администратора и ничего не ставит в систему, кроме
ярлыка в меню «Пуск» и записи в «Приложения и возможности» (для удаления).

---

## Вариант 0. `FreeLLMRouter-Setup-1.0.0.exe` — один клик (рекомендуется)

1. Скачайте `FreeLLMRouter-Setup-1.0.0.exe` (~17 МБ).
2. Двойной клик → «Да» на запрос UAC не будет (установка в профиль пользователя).
   *SmartScreen* может предупредить о неизвестном издателе: «Подробнее» →
   «Выполнить в любом случае» (файл не подписан сертификатом — это self-hosted сборка).
3. Мастер установки: язык → компоненты → папка → «Установить» (20–40 секунд,
   Python и все пакеты уже внутри).
4. На последнем экране — галочка **«Запустить Free LLM Router»**: откроется
   меню, затем браузер с чатом.
5. Дальше — ярлык **Free LLM Router** в меню «Пуск».

Что делает установщик:

* копирует программу в `%LOCALAPPDATA%\FreeLLMRouter` (можно выбрать другую папку);
* использует встроенный Python 3.12 (админ-права и интернет не нужны);
* ставит pip-пакеты из офлайн-копии внутри установщика;
* создаёт `.env` (существующий не перезаписывает), ярлыки и запись удаления;
* запускает сервер и открывает чат;
* удаление — «Приложения и возможности» → Free LLM Router (спросит, удалять ли ключи).

## Вариант 1. ZIP с установщиком (~88 КБ, нужен Python)

1. Распакуйте архив в папку без пробелов, например `C:\FreeLLMRouter`.
2. Двойной клик по **`install.cmd`**.
3. Установщик сам:
   * найдёт Python 3.9+ (а если его нет — поставит Python 3.12 через `winget`);
   * установит пакеты (`fastapi`, `uvicorn`, `httpx`, `python-dotenv`);
   * создаст `.env`, ярлыки в «Пуск» и на рабочем столе;
   * спросит бесплатный API-ключ (можно пропустить и вписать позже);
   * запустит сервер и откроет чат в браузере.
4. Дальше — ярлык **Free LLM Router** в меню «Пуск».

## Вариант 2. Portable ZIP (~15 МБ, Python внутри, офлайн)

Ничего не устанавливается и Python не нужен: интерпретатор лежит в папке
`runtime\`. Распакуйте и запустите `install.cmd` — установщик заметит
`runtime\python.exe` и пропустит установку Python.

## Что происходит при установке

| Файл | Роль |
|---|---|
| `install.cmd` | Установщик: проверки → зависимости → конфиг → ярлыки → первый запуск |
| `launcher.cmd` / ярлык | Меню: запустить/остановить/перезапустить, открыть чат, ключи, статус |
| `uninstall.cmd` | Останавливает сервер, удаляет ярлыки; файлы — по желанию |

Куда что кладётся:

* **Программа:** папка, куда распаковали архив (установщик предлагает
  `%LOCALAPPDATA%\FreeLLMRouter`, если архив запущен «на месте»).
* **Ключи:** `.env` рядом с программой (ставится из `.env.example`, права — только у вас).
* **Журнал сервера:** `%LOCALAPPDATA%\FreeLLMRouter\data\server.log`
* **Порт:** `%LOCALAPPDATA%\FreeLLMRouter\data\port.txt` (если 8000 занят, берётся следующий свободный).

## Бесплатные ключи

Карта не нужна, регистрация — минута. Достаточно любого **одного** ключа:

| Провайдер | Где взять | Переменная в `.env` |
|---|---|---|
| Groq — самый быстрый | console.groq.com/keys | `GROQ_API_KEY` |
| Cerebras — 1 млн токенов/день | cloud.cerebras.ai | `CEREBRAS_API_KEY` |
| Gemini | aistudio.google.com/apikey | `GEMINI_API_KEY` |
| OpenRouter — 50 запросов/день на `:free` | openrouter.ai/keys | `OPENROUTER_API_KEY` |
| Mistral | console.mistral.ai/api-keys | `MISTRAL_API_KEY` |

Вписать ключи позже: ярлык → меню → **6. Вписать API-ключи**
(или `launcher.cmd --keys`). Перезапуск не нужен — сервер перечитает `.env`.

## Для агента

После запуска шлюз доступен на том же порту:

```python
from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="local")
client.chat.completions.create(model="auto", messages=[{"role": "user", "content": "привет"}])
```

Точный адрес (порт может быть другим) показывает пункт меню **7. Подробный статус**
и файл `data\port.txt`.

## Частые вопросы

**SmartScreen: «Windows защитила ваш компьютер».** Скрипты `.cmd`/`.ps1` не
подписаны — это нормально для self-hosted среды. Нажмите «Подробнее» → «Выполнить
в любом случае», или заранее: правый клик по ZIP → «Свойства» → «Разблокировать».

**Порт 8000 занят.** Ничего делать не нужно — среда возьмёт 8001 (и так далее),
а фактический порт запишет в `data\port.txt`.

**Антивирус ругается на `runtime\python.exe`.** Это официальный embedded-Python
с python.org, распакованный без изменений.

**Python не нашёлся, winget не сработал.** Поставьте Python вручную с
python.org/downloads (галочка *Add python.exe to PATH*), затем запустите
`install.cmd` снова — или возьмите portable-сборку.

**Нужно, чтобы сервер запускался автоматически при входе в систему.**
Скопируйте ярлык «Free LLM Router» в папку автозагрузки
(`Win+R` → `shell:startup`) — но тогда при запуске откроется меню;
для тихого старта создайте ярлык на `launcher.cmd --open`.

**Подключить свою базу SQLite с индексом PDF.** В чате: карточка «Индекс PDF» →
**«📂 Указать базу…»** → путь (или кнопка «Обзор…» с системным диалогом) →
«Подключить». Настройка сохраняется в `.env` и применяется без перезапуска.
Альтернатива: меню лаунчера → пункт **8**, или строка `INDEX_DB=...` в `.env` вручную.

**Удаление.** `uninstall.cmd` → сервер остановится, ярлыки удалятся,
файлы и ключи — по вашему выбору.

### История чатов и файлы

Диалоги хранятся локально: `%LOCALAPPDATA%\FreeLLMRouter\data\chats.db`
(папка `data` рядом с программой — только для портативной версии).

- Обновление установщиком историю **не удаляет**.
- Удаление программы спрашивает про историю отдельно; тихая деинсталляция `/S`
  базу не трогает.
- Перенос на другой компьютер: карточка «История» → **⤓ Выгрузить** → на новом
  месте **⤒ Загрузить**. Ключи при этом переносятся отдельно (`Пункт 6` в лаунчере).
- Если папка `data` недоступна для записи (например, программа в `Program Files`
  без прав), запустите лаунчер один раз от обычного пользователя — он пишет
  в `LOCALAPPDATA`, прав администратора не требуется.
