# Где взять бесплатные API-ключи

Ключи не «ищутся» в интернете — каждый выдаётся вашему аккаунту при регистрации
(это как пароль: чужой ключ использовать нельзя и опасно). Зато всё делается
за 1–5 минут: **карта не нужна нигде**, телефон — только у Mistral.

Самый быстрый путь к рабочему чату — **любой один** ключ. Начните с Gemini
(если есть Google-аккаунт) или Groq: обе выдают ключ мгновенно.

> Хотите, чтобы открылись сразу все страницы выдачи:
> `python get_keys.py`  ·  по одной: `python get_keys.py groq`

---

## 1. Groq — самый быстрый, ключ за минуту

| | |
|---|---|
| **Страница** | https://console.groq.com/keys |
| **Вход** | Google / GitHub / email |
| **Карта / телефон** | не нужны |
| **Ключ начинается с** | `gsk_` |
| **Переменная** | `GROQ_API_KEY` |
| **Лимиты** | 30 запр./мин · 1 000/день · 200K токенов/день на модель |

Шаги:
1. Открыть ссылку → **Sign Up** (или войти через Google/GitHub).
2. Слева **API Keys** → **Create API Key** → имя, например `agent`.
3. **Скопировать ключ сразу** — второй раз он не показывается.

## 2. Google Gemini — если есть Google-аккаунт

| | |
|---|---|
| **Страница** | https://aistudio.google.com/apikey |
| **Вход** | аккаунт Google |
| **Карта / телефон** | не нужны |
| **Ключ начинается с** | `AIza…` |
| **Переменная** | `GEMINI_API_KEY` |
| **Лимиты** | ~5–15 запр./мин · 20–1 500/день (зависит от модели и аккаунта) |

Шаги:
1. Открыть ссылку → **Create API key** (при первом визите принять условия).
2. Если спросит проект — выбрать **Create new project** (или существующий).
3. Скопировать ключ из списка.

## 3. Cerebras — самая щедрая квота: 1 млн токенов в день

| | |
|---|---|
| **Страница** | https://cloud.cerebras.ai |
| **Вход** | email или GitHub / Google |
| **Карта / телефон** | не нужны |
| **Ключ начинается с** | `csk-…` |
| **Переменная** | `CEREBRAS_API_KEY` |
| **Лимиты** | 30 запр./мин · 14 400/день · **1 000 000 токенов/день** |

Шаги:
1. Открыть ссылку → **Sign up** (email или GitHub).
2. В консоли слева **API Keys** → **Create / Generate API key**.
3. Скопировать.

## 4. OpenRouter — десятки `:free`-моделей одним ключом

| | |
|---|---|
| **Страница** | https://openrouter.ai/keys |
| **Вход** | Google / GitHub / email |
| **Карта / телефон** | не нужны (50 запросов/день бесплатно) |
| **Ключ начинается с** | `sk-or-v1-…` |
| **Переменная** | `OPENROUTER_API_KEY` |
| **Лимиты** | 20 запр./мин · 50/день на `:free` (1 000/день после разовой покупки $10) |

Шаги:
1. Открыть ссылку → войти.
2. **Create Key** → имя → создать.
3. Скопировать `sk-or-v1-…`.

## 5. Mistral — единственный, где нужен телефон

| | |
|---|---|
| **Страница** | https://console.mistral.ai/api-keys |
| **Вход** | email + подтверждение телефона (один номер на аккаунт) |
| **Карта** | не нужна (план **Experiment**) |
| **Переменная** | `MISTRAL_API_KEY` |
| **Лимиты** | ~1 запр./сек · 500K токенов/мин · до ~1 млрд токенов/мес |

Шаги:
1. Регистрация → подтвердить email и телефон.
2. В консоли убедиться, что активен бесплатный план **Experiment**
   (карту не привязывать).
3. **API Keys** → **Create new key** → скопировать.

## Куда вставить ключ

Ключи хранятся только локально, в файле `.env` рядом с программой.

**Windows** — ярлык «Free LLM Router» → меню → **6. Вписать API-ключи**
(или `launcher.cmd --keys`). Сервер перечитает `.env` сам, без перезапуска.

**Вручную** — открыть `.env` и заполнить нужные строки:

```env
GROQ_API_KEY=gsk_ваш_ключ
CEREBRAS_API_KEY=csk-ваш_ключ
GEMINI_API_KEY=AIza_ваш_ключ
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
MISTRAL_API_KEY=ваш_ключ
```

Пустые строки = провайдер выключен. Порядок автопереключения — в `PROVIDER_ORDER`.

## Проверка, что ключ работает

```bash
python doctor.py        # живой запрос к каждому провайдеру с ключом
python cli.py --status  # какие ключи подхвачены, лимиты и паузы
```

В веб-чате: кнопка **«↻ Ключи»** → слева у провайдера загорится зелёная точка.

| Ошибка | Причина и что делать |
|---|---|
| 401 | ключ скопирован не полностью или с пробелом — вставьте заново |
| 403 | ключ без доступа к этой модели — возьмите другую из списка |
| 429 «per minute» | минутный лимит — подождите ~20 с, роутер сам повторит |
| 429 «per day» | дневная квота модели исчерпана — переключится на другого провайдера |

## Безопасность

* Не публикуйте ключи и не вставляйте их в чужие сервисы — они дают доступ к вашему аккаунту и лимитам.
* Ключи из форумов, GitHub-репозиториев и «бесплатных ключ-сайтов» **не используйте**: их обычно уже отозвали, а бывает — собирают ваши запросы.
* `.env` уже в `.gitignore`; ключи не попадают в архив, если не упаковывать `.env` вручную.
* Ключ утёк — удалите его в консоли провайдера и создайте новый (это одна кнопка).
* Один ключ — один проект: удобнее отзывать и видеть расход.
